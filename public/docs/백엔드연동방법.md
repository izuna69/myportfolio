# 백엔드 및 프론트엔드 연동 가이드 (새 컴퓨터 셋팅용)

이 문서는 새로운 컴퓨터 환경에서 React 프론트엔드와 Spring Boot 백엔드를 처음부터 셋팅하고 연동하여 실행하는 방법을 세세하게 안내합니다.

## 1. 사전 준비 (필수 환경 셋팅)
새 컴퓨터에는 다음 프로그램들이 반드시 설치되어 있어야 합니다.

1. **Java 17 (JDK)**
   - 윈도우의 경우 터미널(CMD/PowerShell)에서 `winget install EclipseAdoptium.Temurin.17.JDK` 입력하여 설치
   - 설치 후 열려있는 터미널을 모두 껐다가 다시 켜고, `java -version`을 쳤을 때 17 버전인지 확인합니다.
2. **PostgreSQL**
   - 백엔드 데이터베이스 용도입니다. 설치 시 설정한 최고관리자(`postgres`)의 **비밀번호**를 꼭 기억해두세요.
3. **Node.js (npm)**
   - 프론트엔드 구동을 위해 필요합니다.

---

## 2. 데이터베이스(DB) 셋팅
1. **DBeaver** 같은 DB 클라이언트 프로그램을 엽니다.
2. PostgreSQL 연결을 생성합니다. (기본값 설정: `Host: 127.0.0.1`, `Port: 5432`, `User: postgres`, `Password: 설치시 비밀번호`)
3. 접속 후, 좌측 메뉴에서 새로운 데이터베이스(Database)를 생성합니다.
4. 새 데이터베이스의 이름은 반드시 **`myportfolio`** 로 지정하고 생성합니다. (SQL 명령어: `CREATE DATABASE myportfolio;`)

---

## 3. 백엔드(Spring Boot) 셋팅 및 실행
1. 에디터(VS Code 등)에서 전체 프로젝트 폴더를 열고 백엔드 폴더(`myportfolio_back`) 안의 다음 파일을 엽니다.
   - 경로: `src/main/resources/application.yml`
2. 파일 내에서 `spring.datasource.password` 항목을 방금 DB 접속에 사용했던 **본인의 실제 비밀번호**로 수정합니다.
   ```yaml
   spring:
     datasource:
       url: jdbc:postgresql://localhost:5432/myportfolio
       username: postgres
       password: 여기에_비밀번호_입력  <-- 이 부분을 새 컴퓨터 DB 비밀번호에 맞게 수정!
   ```
3. 터미널을 열고 `myportfolio_back` 폴더 경로로 이동(`cd myportfolio_back`)한 뒤 다음 명령어를 실행합니다.
   - 윈도우 CMD의 경우: `gradlew bootRun`
   - Mac/Linux/PowerShell의 경우: `./gradlew bootRun`
4. 로그가 주욱 올라가고 `Started BackendApplication` 메시지가 뜨면 백엔드(8080 포트) 준비 완료입니다! **(이 터미널 창은 끄지 말고 계속 켜두세요)**

> **💡 주의: 만약 새 PC의 PostgreSQL 설정이 다르다면?**
> *   **비밀번호가 다른 경우:** `password:` 부분을 새 PC의 PostgreSQL 비밀번호로 똑같이 맞춰주세요.
> *   **데이터베이스 이름이 `myportfolio`가 아닌 경우:** 
>     `url: jdbc:postgresql://localhost:5432/myportfolio` 의 맨 끝부분 `myportfolio`를 본인이 생성한 DB 이름으로 바꿔주세요.
> *   **PostgreSQL 아이디가 `postgres`가 아닌 경우:** 
>     `username:` 부분을 본인의 아이디로 변경해주시면 됩니다.

---

## 4. 프론트엔드(React) 셋팅 및 실행
1. 에디터에서 **새로운 터미널 탭**을 하나 더 엽니다.
2. 프론트엔드 폴더(`myportfolio`) 경로로 이동합니다. (`cd myportfolio`)
3. 새 컴퓨터이므로 패키지 모듈들을 처음부터 다시 설치하기 위해 다음 명령어를 입력합니다.
   ```bash
   npm install
   ```
4. 설치가 끝나면 개발 서버를 실행합니다.
   ```bash
   npm run dev
   ```
5. 화면에 나오는 `http://localhost:5173/` 주소를 눌러 웹 브라우저로 접속합니다.

---

## 5. 연동 테스트 (프로젝트 업로드)
1. 브라우저 화면을 보면 하단 프로젝트 목록이 텅 비어있을 것입니다. (방금 만든 새 DB라서 정상입니다!)
2. 화면 우측 상단의 **[+ Add Project]** 버튼을 클릭합니다.
3. 첨부할 이미지 파일(썸네일)을 하나 고르고, 영어/일본어 제목 등 양식을 모두 작성합니다.
   - `Tech Stacks` 항목은 `React, Spring Boot` 처럼 **쉼표(,)**로 구분해서 적습니다.
4. **[Add Project]** 버튼을 눌러 업로드합니다.
5. 팝업창이 닫히면서 화면에 내가 방금 올린 프로젝트 카드가 즉시 나타난다면 **프론트엔드와 백엔드 연동 셋팅이 100% 성공**한 것입니다! 🎉

*(참고: 업로드된 이미지 파일들은 깃허브에 올라가지 않고 새 컴퓨터의 `myportfolio_back/uploads/` 폴더에 물리적으로 저장되며, 글 정보는 PostgreSQL DB에 기록됩니다.)*
