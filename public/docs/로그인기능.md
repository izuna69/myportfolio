# 관리자 로그인 기능 기획안

## 1. 개요
*   **목적:** 아무나 포트폴리오 프로젝트를 추가/수정/삭제하지 못하도록 관리자용 로그인 기능을 도입합니다.
*   **접근 권한:**
    *   **비로그인 사용자 (일반 방문자):** 프로젝트 목록 열람(조회)만 가능합니다.
    *   **로그인 사용자 (관리자):** 프로젝트 조회뿐만 아니라 추가(Add), 수정(Edit), 삭제(Delete) 버튼이 활성화되어 기능을 사용할 수 있습니다.
*   **계정 정보 (하드코딩):**
    *   **아이디:** `kim`
    *   **비밀번호:** `1234`

---

## 2. 프론트엔드 (React) 구현 계획
1.  **로그인 UI:**
    *   화면 맨 아래(Footer) 우측이나 눈에 띄지 않는 곳에 자물쇠 아이콘(🔒)이나 작은 'Admin' 버튼을 배치합니다.
    *   버튼 클릭 시 ID와 Password를 입력할 수 있는 팝업(LoginModal)을 띄웁니다.
2.  **상태 관리 (Auth State):**
    *   로그인에 성공하면 브라우저의 `sessionStorage` 혹은 `localStorage`에 로그인 상태(토큰)를 저장합니다.
    *   로그인 상태일 때만 `[+ Add Project]` 버튼과 카드 위 마우스 오버 시 나오는 `[✏️]`, `[🗑️]` 버튼이 보이도록 조건부 렌더링을 적용합니다.

---

## 3. 백엔드 (Spring Boot) 구현 계획
1.  **로그인 API (`POST /api/auth/login`) 추가:**
    *   아이디와 비밀번호를 받아서 `kim` / `1234`가 맞는지 확인합니다.
    *   맞으면 간단한 인증 토큰(예: `admin-token`)을 프론트엔드로 반환합니다.
2.  **보안 처리 (Interceptor 설정):**
    *   게시물 추가(`POST`), 수정(`PUT`), 삭제(`DELETE`) API 요청이 들어올 때마다, 요청 헤더에 관리자 토큰이 있는지 검사하는 `AuthInterceptor`를 추가합니다.
    *   토큰이 없거나 틀리면 `401 Unauthorized` 에러를 뱉어내어, 누군가 악의적으로 API만 호출해 데이터를 지우는 것을 서버 단에서 원천 차단합니다. (조회 `GET` 요청은 토큰 없이도 허용)
