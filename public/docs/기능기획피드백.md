# 기능 기획 피드백

작성해주신 `기능기획.md` 문서를 바탕으로, 포트폴리오에 프로젝트 추가 기능을 구현할 때 고려해야 할 제안 사항들을 정리했습니다. 기획하신 데이터 항목들은 현재 포트폴리오 구조와 완벽하게 일치합니다!

## 1. 📊 현재 데이터 구조와의 완벽한 일치
기획하신 항목들은 이미 저희가 다루고 있는 `projects_list.ts`의 데이터 구조와 아주 잘 맞습니다.
* **사진** ➔ `image`
* **프로젝트 이름** ➔ `title`
* **프로젝트에 대한 설명** ➔ `description`
* **깃허브/데모 링크** ➔ `links: { demo, github }`
* **기술스택 태그** ➔ `stack` (배열)

ㅇ

## 3. 🌐 다국어(일본어/영어) 지원 고려
방금 영어와 일본어 전환 기능을 추가했기 때문에, 새로운 프로젝트를 추가할 때는 **두 가지 언어에 대한 데이터**가 모두 필요합니다.
* 화면에서 프로젝트를 추가하는 기능(UI)을 만든다면, **프로젝트 이름**과 **프로젝트 설명**은 '영어 입력칸'과 '일본어 입력칸'을 분리해서 입력받도록 기획을 조금 확장해야 합니다.

## 4. 🖼️ 이미지(사진) 업로드 방식
사진을 어떻게 등록할지에 대한 기획도 추가되면 좋습니다.
* 이미지를 직접 파일로 업로드할 것인지? (이 경우 이미지를 저장할 서버가 필요합니다. AWS S3 등)
* 아니면 외부 인터넷에 올라가 있는 **이미지 주소(URL)**만 텍스트로 입력받아서 보여줄 것인지? (백엔드 없이 가장 쉽게 구현하는 방법)
