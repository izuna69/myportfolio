---

## 📌 프롬프트 (여기서부터 아래 내용을 모두 복사해서 AI에게 입력하세요)

안녕하세요! 저는 프론트엔드(React)로 포트폴리오 웹사이트를 만들고 있습니다. 여기에 '프로젝트 추가 기능'을 위한 백엔드 API 서버를 구축하려고 합니다. 
아래 요구사항에 맞게 **Spring Boot 백엔드 코드 세트(Entity, DTO, Controller, Service, Repository, 설정 파일 등)**를 작성해 주세요.

### 1. 기술 스택 (Tech Stack)
* **Language/Framework**: Java 17 이상, Spring Boot 3.x
* **Database**: PostgreSQL, Spring Data JPA
* **Storage**: 로컬에 저장(멀티 파트)
* **기타**: Lombok, Spring Web, Validation

### 2. 데이터베이스 스키마 및 엔티티 (Entity)
프론트엔드에서 영어/일본어 다국어를 지원하고 있으므로, 데이터는 언어별로 나누어 저장해야 합니다. 기술 스택은 문자열 리스트로 저장합니다.

**[Project Entity 구조]**
* `id` (Long, PK, Auto Increment)
* `titleEn` (String) : 프로젝트 이름 (영어)
* `titleJa` (String) : 프로젝트 이름 (일본어)
* `descriptionEn` (Text) : 프로젝트 설명 (영어)
* `descriptionJa` (Text) : 프로젝트 설명 (일본어)
* `imageUrl` (String) : 로컬 서버에 업로드된 이미지 다운로드 URL
* `demoLink` (String) : 실제 데모 링크 (선택사항)
* `githubLink` (String) : 깃허브 링크 (선택사항)
* `stacks` (List<String>) : 기술 스택 태그 (예: ["React", "Spring Boot", "MySQL"]) -> `@ElementCollection` 사용

### 3. 구현해야 할 API 스펙 (Endpoints)

**1) 프로젝트 추가 API (POST `/api/projects`)**
* `Content-Type`: `multipart/form-data`
* **Request 파라미터**:
  * `image`: MultipartFile (이미지 파일)
  * `requestDto`: JSON String (titleEn, titleJa, descriptionEn, descriptionJa, demoLink, githubLink, stacks) -> `@RequestPart` 사용
* **동작 로직**:
  1. 전달받은 `image` 파일을 로컬 디렉토리(예: uploads/)에 업로드
  2. 로컬에서 접근 가능한 이미지 URL을 `imageUrl` 필드에 매핑
  3. 나머지 정보들과 함께 DB에 저장
  4. 저장된 엔티티 반환

**2) 프로젝트 목록 조회 API (GET `/api/projects`)**
* 등록된 모든 프로젝트 데이터를 반환 (프론트엔드에서 리스트 렌더링용)

### 4. 특별히 작성해 주셨으면 하는 코드
전체적인 구조를 다 짜주시면 좋겠지만, 특히 다음 부분들을 상세히 작성해 주세요.

1. **`LocalFileUploader` 서비스 클래스**: `MultipartFile`을 받아 로컬 폴더에 업로드하고 URL을 리턴해주는 로직
2. **Controller와 DTO**: `multipart/form-data`에서 JSON 데이터와 파일을 동시에 안전하게 받는 예외 처리 완벽한 컨트롤러 로직
3. **CORS 설정**: 프론트엔드(React, 보통 `http://localhost:5173`)에서 API를 호출할 수 있도록 WebMvcConfigurer를 통한 전역 CORS 설정
4. **`application.yml` 설정 템플릿**: PostgreSQL DB 연결 설정과 로컬 업로드 경로를 넣을 수 있는 설정 파일 형태
